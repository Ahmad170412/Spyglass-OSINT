# The authoritative dependency set lives in pyproject.toml:
#
#     pip install -e .                 # core CLI only
#     pip install -e ".[all]"          # + recon engines, web console, metadata
#
# There is no PyPI package; the project is distributed from GitHub only, and
# the form above is the supported install. This file exists so the shorter
# `pip install -r requirements.txt` still resolves from the repo root, and it
# installs the local checkout with every extra so the source tree is runnable
# exactly as an installed copy would be.
#
# Note on `shodan`: it is deliberately absent. website.py shells out to the
# Shodan *command-line client* (subprocess, _phase_shodan_ports), it never
# imports the Python library of the same name — so installing `shodan` from pip
# satisfies nothing here. The CLI comes from brew/apt, and setup.sh handles it.
-e .[all]
